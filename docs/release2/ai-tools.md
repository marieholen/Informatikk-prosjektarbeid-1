# Ai usage in release 2 

As mentioned in earlier release: All members understand that it is acceptable to use AI to help perform tasks, provided that every solution is fully understood before it is submitted for review. Each member is expected to take ownership and responsibility for the solutions they deliver.  

## Some mentions of AI usage in release 2
- AI was used to provide guidance and support during development. It offered assistance with problem-solving approaches and relevant code examples for issues on Git, as well as suggestions for potential code improvements. The tool also helped create tests that covered additional functionality and explained error messages encountered during development, proposing possible solutions.

- AI was used in the SessionManager to assist in implementing functionality for loading only the recipes belonging to the current user.

- AI was used in Issue 86 (PR 108) to scale up all elements in the window, as doing this manually would have been time-consuming.

- AI was used in the EditRecipeController file Issue 113 (PR 115) and provided guidance when writing test Issue 98 (PR 139) to save time and improve the quality of the code. The tool was mainly used to generate code suggestions and help identify potential improvements in structure and logic. All generated code was reviewed, tested, and modified by the issue owner and the team to ensure it fit the project’s requirements and coding standards.

- AI has been used in document files for translation and to improve grammar and sentence structure.
