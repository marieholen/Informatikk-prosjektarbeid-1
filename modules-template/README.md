# KnitSpace

## Application description
- Storage space for all your knitting projects
- Sort your recipes based on skill level.
- Sort types of clothing e.g. sweaters, scarf, socks, ect.
- Sort knitting needles sizes
- Sort yarn types. 
- Overview to track your knitting projects (to do, in progress, done).


## User stories
- As a knitting prodigy, I wish to have an overview of all my knitting recipies, so that I can quickly find and choose which project to work on. 

- As a traveller, I wish to have all my recipes in one place digitally, so that I can bring the recipes with me at all time.
